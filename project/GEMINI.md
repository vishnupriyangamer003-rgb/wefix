# PROJECT DIRECTORY RULES

* **Active Workspace**: All new code, static websites, and Laravel projects must be built inside this `project/` directory.
* **MANDATORY GIT BACKUP**: Before performing any UPDATE or DELETE operations on files here, ensure an active Git commit or backup exists.
* **UI Testing Requirement**: Detail-test all UI changes across screen sizes and verify company info (`companyinfo.txt`) and logo (`logo.jpeg`) integration before completing work.
